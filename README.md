# E-Commerce Web Application

A web-based online store built using PHP, MySQL, HTML, and CSS.

## Features
- User registration and login
- Product catalog
- Shopping cart and checkout
- Order placement and tracking
- Admin product management
- Admin order management
- Role-based access control

## Technologies Used
- PHP
- MySQL
- HTML
- CSS
- XAMPP
- Visual Studio Code

## Running Locally
1. Install XAMPP.
2. Place the project folder inside `C:\xampp\htdocs\`.
3. Start Apache and MySQL.
4. Open `http://localhost/mystore/` in your browser.
5. Import the project database in phpMyAdmin before using database features.
